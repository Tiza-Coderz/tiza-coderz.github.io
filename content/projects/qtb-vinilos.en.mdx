## The problem

A record and vinyl store with loyal customers, but selling **through social media and messages**: no catalog with real stock, no order history and every delivery coordinated with couriers by phone.

## The solution

We built **all three parts of the product**:

- **Backend (REST API)**: catalog with search and filters, cart, orders, stock control, role-based authentication, one-time code verification (OTP) and an admin panel.
- **Web store**, fast and conversion-focused: product pages, cart and checkout.
- **Courier app** (Flutter): delivery assignment, order status updates, proof of delivery and notifications.
- Everything packaged with **Docker** so it runs the same in development and production.

## The result

A single system where **sales, management and delivery talk to each other**: an order placed on the web shows up in the panel, gets assigned to a courier and is closed with proof of delivery. It's the project that best shows we can own a complete product.
